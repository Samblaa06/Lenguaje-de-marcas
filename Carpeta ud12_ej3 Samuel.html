Ficha Técnica: Python

Documento de referencia rápida sobre el lenguaje de programación.

Información General

  • Tipo: Lenguaje interpretado de alto nivel y tipado dinámico.
  • Primera publicación: 20 de febrero de 1991 por Guido van Rossum.
  • Entorno recomendado: Se suele programar mediante un IDE como VS Code o PyCharm.
  • Versiones destacadas: El fin de soporte de la rama Python 2.x marcó el salto definitivo hacia Python 3rd edition (Python 3.x).

Conceptos Clave

Un bytecode es una forma de código intermedio compilado que la máquina virtual de Python (PVM) interpreta para ejecutar las instrucciones en el hardware subyacente.

Uso Básico y Atajos

Para comprobar la versión instalada en la terminal, se ejecuta el siguiente comando:

python --version

Para salir de la consola interactiva (REPL) en entornos Linux o macOS, presiona Ctrl + D (o Ctrl + Z seguido de Enter en Windows).
